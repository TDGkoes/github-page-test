# RFP-03. 가상 구매 데이터 분석 및 AI 의사결정 지원

> 합성 테스트 문서입니다. 기관명, 수치, 시스템, 일정은 모두 가상이며 실제 고객·사업과 무관합니다.

## 테스트 메타정보 (RFP 본문 외)

### Microsoft 서비스·기술 기준

이 기준은 Microsoft 제품·서비스 및 개발 기술로 요구 기능을 구현할 수 있는지 평가하기 위한 테스트 전제입니다. Microsoft 제품이 제공하는 기능의 범위와 제안사의 구축·운영 인력 제공 여부는 별개로 판단합니다.

- 데이터 통합·변환·분석은 Microsoft Fabric의 Data Factory, OneLake, Data Engineering·Data Warehouse 기능을 후보로 검토하고, 시각화·공유는 Power BI를 후보로 검토한다.
- 역할·데이터 접근은 Microsoft Fabric 및 Power BI의 권한·보안 기능으로 설계할 수 있다. 구체적인 권한 모델, 라이선스, 용량·지역 및 데이터 거버넌스 설정을 확인해야 한다.
- 생성형 AI 및 모델 기반 기능은 Microsoft Foundry의 모델·도구·에이전트 기능을 후보로 검토한다. 사용할 모델과 지역·용량, 데이터 처리·보안 승인, 평가 기준, 사람 검토 절차를 사전에 확인해야 하며 결과 정확도나 사업 성과는 보장되지 않는다.
- 데이터 품질 자동 수정에는 업무별 규칙과 담당자 승인 기준이 필요하다. Fabric이나 AI 기능이 원천 데이터의 의미를 자동으로 확정하거나 모든 오류를 안전하게 정정한다고 가정하지 않는다.
- Microsoft 제품은 금융 관련 법률 판단을 자동 확정하거나 사업별 법규 준수 인증·보증을 대신하지 않는다. 제품의 보안·규정 준수 기능과 발주기관의 법률·통제 책임을 구분한다.

### 분류 기준

- **지원 범위 내**: 관련 Microsoft 제품의 문서화된 기능으로 요구사항을 직접 구현할 수 있고 필수 전제조건이 명시되어 있음
- **일부 지원 가능**: Microsoft 제품을 기반으로 구현할 수 있으나 사용자 지정 개발, 데이터 준비·검증, 추가 라이선스·용량, 지역 가용성, 보안 승인 또는 외부 연계가 필요함
- **지원 불가**: Microsoft 제품·서비스만으로 충족할 수 없는 자동 규제 판단·인증 보증 또는 100% 정확도와 같은 절대 결과 보장이 핵심 조건임

각 분류에 Microsoft 제품·기능 근거, 전제조건, 라이선스·외부 의존성, 확인 질문을 함께 제시합니다. 제품명만으로 지원을 확정하지 말고 현재 GA/Preview 상태와 지역 가용성을 확인합니다. 아래 요구사항에는 정답 라벨이 포함되어 있지 않습니다.

## 1. 사업 개요

### 1.1 발주기관

가상 금융기관 **다온상호금융**

### 1.2 사업명

구매 데이터 분석 및 심사 업무 지원 플랫폼 구축

### 1.3 추진 배경

다온상호금융은 지점과 온라인 채널에서 수집되는 구매·거래 데이터를 통합해 운영 현황을 분석하고자 한다. 별도 심사 업무의 자료 검토 시간을 줄이는 방안도 함께 검토하되, 데이터 활용 목적과 모델 운영 정책은 아직 확정되지 않았다.

### 1.4 사업 목표

- 승인된 데이터 소스를 정기적으로 통합한다.
- 운영 담당자가 지표와 추이를 조회할 수 있는 분석 화면을 제공한다.
- 심사 담당자의 자료 확인을 보조하는 기능의 적용 가능성을 검토한다.

## 2. 사업 범위

- 데이터 소스 및 지표 정의 워크숍
- 승인된 구조화 데이터의 수집·변환 및 저장
- 운영 대시보드와 정기 보고서 제공
- 데이터 품질 점검 및 운영 절차 문서화
- AI 보조 기능의 활용 가능성 검토 및 제한된 시험 적용안 제시

## 3. 요구사항

| ID | 요구사항 |
|---|---|
| DAT-01 | 발주기관이 데이터 항목 설명, 읽기 전용 계정 및 테스트 접속 정보를 제공하는 3개 관계형 데이터베이스에서 거래 데이터를 매일 수집한다. |
| DAT-02 | 합의된 지표 정의에 따라 월별 거래 건수, 상품별 합계, 채널별 추이를 조회하는 대시보드와 정기 CSV 보고서를 제공한다. |
| DAT-03 | 분석 데이터와 화면에 대해 담당자 역할별 접근 권한을 설정하고, 주요 데이터 갱신 이력을 확인할 수 있게 한다. |
| DAT-04 | 기존 거래 데이터의 누락·중복·코드 오류를 사업자가 모두 자동 정정한다. 발주기관은 원천 데이터 샘플과 품질 기준을 아직 제공하지 않는다. |
| DAT-05 | 고객 거래 내역과 심사 문서를 활용하는 생성형 AI 질의 기능을 제공한다. 사용 가능한 모델, 데이터 보관 위치, 개인정보 처리 승인 및 테스트 자료는 착수 시 협의한다. |
| DAT-06 | 과거 사례를 학습해 신규 신청자의 상환 가능성을 예측하고 심사 결과를 자동 승인 또는 거절한다. 사람의 검토 단계 없이 운영하며, 예측 정확도 99.99% 이상을 계약상 보장한다. |
| DAT-07 | 예측 기능과 데이터 처리 전 과정이 적용 가능한 금융 관련 법령과 규정을 모두 준수함을 사업자가 인증하고 결과를 보증한다. |
| DAT-08 | 배치 수집 실패, 데이터 갱신 지연, 파일 형식 오류를 운영자가 확인할 수 있도록 상태와 기본 오류 기록을 제공한다. |
| DAT-09 | 발주기관이 제공하는 데이터 사전과 지표 정의를 바탕으로 분석 항목 및 산출 로직 문서를 작성하고 담당자 검토를 받는다. |

## 4. 비기능 요구사항

- 운영 데이터는 발주기관이 승인한 환경에 저장한다.
- 사용자 권한과 데이터 접근 기록을 관리한다.
- AI 시험 적용 여부와 사용 데이터는 발주기관의 보안·개인정보 승인 이후 확정한다.
- 모델 결과는 검토 가능한 근거와 한계를 사용자에게 전달하는 방안을 제안한다.

## 5. 수행 및 제안 요청

제안사는 데이터 준비도와 선행 조건, 분석 기능과 AI 기능의 경계, 사람의 검토 절차, 보안·개인정보 확인 사항, 단계별 검증 방안을 제시한다. 모델 정확도나 규제 준수 결과는 확인 가능한 근거 없이 보장값으로 제시하지 않는다.
